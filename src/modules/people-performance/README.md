# people-performance 模块

非主播员工的试用期与正式绩效管理。

- 2个月试用期生成一个完整考核周期。
- 6个月试用期在第1、3、5个月分别生成周期；第1、3月在直接上级评估后进入HR校准，校准后完成并向员工展示评级，无员工确认或转正结论；第5月保留HR校准、转正结论与员工确认。
- 正式绩效以季度为父周期，拆成三个需要完整流转的月度周期。
- 完整流程：目标制定 → 直接上级审核 → 员工自评 → 直接上级评估 → 隔级上级评估 → HR校准 → 员工确认。
- 最终得分 = 直接上级评分合计 × 40% + 隔级上级评分合计 × 60%。
- HR校准可以退回隔级评估；员工结果确认只允许确认，不能退回。
- 试用期评级由 HR 在校准环节从“超越预期、符合预期、待改进、不符合预期”中独立选择，不根据分数自动换算；总分仍保留。正式员工绩效等级规则不变。
- 员工只有在 HR 校准完成进入员工确认或已完成状态后，才能看到试用期评级。旧 S-D 结果不自动转换为新评级。
- 每个动作写入不可变事件；节点通知通过 dedupe key 保证幂等。
