# 商务招募

线上主播候选人从商务登记、商务初评、运营复评到入会签约的流程模块。

- `candidate_edit`：登记基础资料并完成商务初评。
- `operation_review`：填写运营复评、最终评级和带教运营。
- `signing_manage`：维护入会、签约与首次开播日期。

数据范围按招募商务或带教运营归属计算；`self` 可查看本人招募或本人带教的候选人。

## 线上招募月度统计

入口：商务招募 → 线上招募 → 月度统计。默认北京时间当月，可选择月份及经纪人，点击汇总人数查看对应主播明细，每页20条。

- 入会人数：登记的入会日期在所选自然月内。
- 有效主播：自入会起累计开播至少7个不同自然日、总时长至少14小时，计入首次同时达标的月份，每个主播只计一次。跨月不清零。
- 有效开播：所选月内开播至少20个不同自然日、总时长至少60小时，每月独立统计，不限入会月份。
- 来源：按抖音号或UID唯一匹配 `anchor_profile`，汇总 `anchor_daily.live_duration_1d`（小时，开播总时长）。不使用近30天滚动汇总，不使用有效时长代替总时长。身份歧义、重复UID、非抖音账号不计直播达标。
- 已知首播早于已采集历史时，首次达标月标为待核对，不将观测到的后续达标误认为首次；页面提示最新数据日期和未匹配账号。
- 统计权限：管理员沿用权限面板准入定义（permissions模块有权限点，含超级管理员）以及应急管理员，可查看全部并按经纪人筛选。部门负责人按后台“管理部门”递归包含子部门，可查看本人及部门经纪人的招募数据；个人显式 self/none 设置仍生效。其他人员仅看本人，普通 all 范围不自动获得全员统计。所有范围均按 recruiter_user_id 过滤，不继承带教或委托关系；筛选项、汇总和明细共用范围，每次服务端查询重新鉴权并拒绝范围外经纪人ID。

示例：10月30日入会，10月31日至11月6日开播7天合计14小时，入会人数计10月，有效主播人数计11月，12月不会重复计入。
