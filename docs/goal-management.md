# 目标管理（本地首版）

入口 `/goals`；工作台底部 `/dashboard` 展示本月已发布目标。两处使用相同数据和权限。

## 使用

1. 新建／调整草稿：填写周期（如 `2026-10`、`2026-Q4`）、项目、业务线、负责人、部门、指标、目标值与统计口径。未确定的目标值留空；负责人须绑定系统员工ID。同名员工需核对后选择，不能仅以姓名作为权限依据。
2. 斗地主、三冰、造化选择抖音来源，捕鱼选择3D／UE4／URP，按左侧类别、右侧字段选指标，再填写目标值和统计账号。标准指标固定名称、单位与取数标识，自动读取实际值；可预览完成数。人工指标用于招聘等，确认后自行填报累计值、截至日及依据。真实零填0，未知保持空。
3. 单独发布后进入工作台；已发布目标的调整需要发布权限。归档后保留历史，停止填报并从首页移除；有权限者可重新开启。
4. 调整周期、项目、业务线、负责人、部门、指标、单位或统计口径，会清空当前实际值，原值留在调整记录中。仅调整目标值保留实际值。复制只复制定义，保持草稿且不复制实际值，可自行指定下期。
5. 月目标可关联同范围、同口径的季度指标，已分配目标不能超过季度值。同一季度指标不能重复配置同一月份。季度口径调整会同步关联月目标并分别留痕；跨范围或已归档的关联月目标会阻止调整。季度实际独立填报，不自动相加月度UV或ROI；ROI不支持相加拆分。

## 权限

“用户与权限”增加独立“目标管理”板块，包含查看、创建草稿／填报、发布／调整／归档三个权限点，搭配本人／负责团队／全部范围。普通岗位默认关闭；超级管理员和应急管理员可管理。已有模块的岗位或个人授权不会因本功能而改变。

团队范围指直接管理部门及本人负责目标；创建、变更负责人、查询目标、查询人员选项、历史记录均在服务端验证。委托视图只显示委托负责人的目标，不额外读取全公司业务源。重新指派后，不向新负责人展示其原本无权读取的历史快照。

## 综合达成率与指标权重（2026-10-16）

- 工作台项目摘要和目标管理分组摘要展示综合达成率，明细保留单项进度。默认所有指标自动平均分配；新建或统一调整时，可切换“自定义权重”，逐项输入0～100%，合计必须为100%。新增指标不会沿用其他指标的权重，须重新分配或切回平均分配。
- 综合达成率为各指标标准化得分乘以其权重之和，使用未四舍五入的实际值计算，最后保留两位小数。累计量、数量和正向门槛得分为实际值÷目标值，每项限制在0～100%；上限指标满足上限计100%，超过计0%。比率门槛须大于0，未配置时不计已取得数据。单项仍可展示超过100%的真实达成率。
- 示例：单项42.03%及0%，各占50%，综合为21.02%。若42.03%只是单项显示的四舍五入结果，综合按原始数值计算，末位可能不同。
- 缺少实际值、目标值、确认口径或来源授权的指标保留权重并暂按0贡献，显示数据待补齐；全部不可用时显示待同步／配置，不显示0%。部分来源数据有实际值时计算已同步部分，仍保留不完整提示且不判定完全达成。真实记录的0可正常参与。
- 仅当前可见、未删除、未归档的指标参加管理分组计算，工作台另外限定为已发布指标。权重在各自展示范围内归一化；归档、发布或权限范围变化后，剩余指标按剩余权重折算。全为0权重时提示待配置。工作台按项目合并不同负责人分组，各组保存的百分比在该项目可见范围内归一化，不隐含额外负责人权重。
